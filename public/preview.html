How transparent is your council,

An independent, open-methodology scoreboard for every parish, town and city council in England. No surveys. No self-reports. Every score is reproducible from public data using our open-source engine.

Observable evidence only No paywalled scores Open-source engine Audit CSV for every council

Three receipts, every time

Every score ships with three public artefacts. If any doesn't match, the score is wrong — and we want to know.

The methodology

Every rule, every weight, every edge case, written in plain English. One document; no appendices contradicting each other.

The engine

A single Python script under 20 unit tests. Fork it, read it, run it on the audit CSV, reproduce every number.

The audit CSV

Every council: inputs, verdicts, earned, max, denominator, score. Updated nightly. Downloadable.

Methodology

Four pillars. Fourteen indicators. One honest number.

We measure observable public transparency — not council quality, not resident satisfaction, not value for money.
